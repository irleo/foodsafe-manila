# Capstone Contributions

FoodSafe Manila is a team capstone. The attribution below records the primary developer's account of the work; Git history can supplement it but does not capture every design discussion or UI collaboration.

## Primary development: irleo

I carried out most of the project's development and integration, spanning system design, application implementation, regression checks, and deployment setup. I brought the React staff dashboard, shared Express/MongoDB backend, Flutter application, and forecasting pipeline together into the capstone system.

| Area | Primary contribution |
| --- | --- |
| System design | Shared API/data architecture, official-case versus citizen-report boundaries, and client/backend integration |
| Web dashboard | Routing, authenticated API access, charts/maps, dataset workflows, report review, and administration |
| Backend and mobile integration | Account/session flows, policy and reporting workflows, data access, and integration with the citizen application |
| Forecasting | Python forecast integration, evaluation/presentation, and GitHub worker orchestration |
| Engineering and delivery | Regression checks and Render/environment deployment configuration across the shared system |

These areas describe my primary responsibilities within the team; they do not imply exclusive authorship of every file.
